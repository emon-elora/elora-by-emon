ELORA BY EMON — PROFESSIONAL STOREFRONT
==========================================
This package is a polished, responsive storefront prototype based on the
Facebook Page screenshot supplied by the owner.

Included:
- Premium responsive storefront design
- Fashion + Beauty categories
- Product filtering
- Product search
- Shopping bag with localStorage
- Order checkout form
- WhatsApp order handoff
- Mobile navigation
- Brand colors and supplied logo
- Bangladesh currency formatting
- Nationwide/COD messaging

Important:
This is a front-end storefront. For a live production store, connect it to:
1. A real product database/CMS
2. Admin dashboard
3. Image storage/CDN
4. Secure server-side order processing
5. Payment gateway if desired (bKash/Nagad/SSLCommerz)
6. Domain + HTTPS hosting
7. Facebook/Instagram links and analytics

To customize products, edit the `products` array in app.js.
Replace the placeholder product visuals with real product images for launch.
